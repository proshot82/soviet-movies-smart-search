## Что не сделано (необязательное)
- Бэклог каталога — косметика OCR в нескольких записях (`veto/ВЕТО_Ф6_П3а.md` §7, `veto/ВЕТО_Ф6_П3в.md` §4/§6; id 4074 «Ло одноименному»),
  9 концертных записей с титровой строкой, 62 «Фитиля» со студиями сюжетов, 118 аннотаций без конечного знака (как в печати).
- Публикация движка для посторонних: лимит запросов на адрес и дневной потолок расходов (≈ 20 тыс. входных токенов gpt-5.5 на запрос),
  нормальный сервер вместо отладочного Flask, HTTPS. Сейчас движок рассчитан на запуск на своём компьютере (`serve.bat`).
- Расширение функций по `handoff/ROADMAP_расширение_поиска.md` (режим «Каталог», точный диапазон лет, поиск по названию, экспорт,
  статистика, «похожие фильмы», полки) — отдельные задачи по желанию владельца, переэмбеддинг не нужен.
- Новые замеры качества имеют смысл только на новом независимом наборе запросов (нынешние 85 использованы при настройке).

`scripts/p4/bench/bench_search.py` и `bench_set.json` и запустить там.

## Куда положить папку
Внутрь своего пользовательского каталога: C:\Users\<имя>\GFF_cowork
(папку на другом диске приложение может отклонить).

## Чего здесь быть НЕ должно
openai_key.txt, gosfilmofond.db, эмбеддинги — движку Ф5 не нужны.

## Как запустить
Движок — на своём компьютере: в папке движка (где `gosfilmofond.db` и `openai_key.txt`) двойной щелчок по `serve.bat` (или
`python film_search.py serve`) — браузер откроется сам. Обновлённые скрипты берутся из `scripts/p4/` поверх старых.
Продолжение работы в Cowork: из проекта «Госфильмофонд» подключить эту папку и написать, что делать: бэклог каталога — по
`handoff/PROMPT_Ф6_сборка_COWORK.md` (правила пакетов и вето); правки движка — по `scripts/p4/README_П4.md`; расширения — по
`handoff/ROADMAP_расширение_поиска.md`.
