# Реконструкция мастер-индекса — index_master_v18r.json (31.08.2026)

Оригинал `index_master_v18.json` утрачен вместе с чатом ф17. Файл пересобран как проекция двух живых
источников, без единого придуманного значения; каждая строка несёт `provenance`, каждый титул — `title_source`.

## Источники и правила

- **Карточные строки (7172)** — из `alignment_v17.json`: `xlsx_row` (= колонка «№» эталона), `num` (= `idx_num`,
  исправленный номер мастера), `title_canon` (= `master_title`), `vol` (= `source` записи каталога), `cat_pos`.
- У 107 строк `master_title` в alignment пуст — взят титул каталога (канонизирован в Ф3 по мастеру), `title_source` это фиксирует.
- У 44 строк номер мастера отличается от сырого номера xlsx (правки Ф1–Ф4) — сырой сохранён в `num_corrected_from_xlsx`.
- Сырые поля xlsx (`xlsx_title`, `xlsx_num`, `xlsx_year`, альт-названия из «Примечания») приложены к каждой строке ≤ 7195.
- **Синтетические строки (8, xlsx_row > 7195)** — добавлены в Ф2–Ф4 (закрытие дыр мастера, вставка «Зоя», литеры 1981а/2031а); xlsx-полей у них нет.
- **Некарточные строки xlsx (31)** — не привязаны ни к одной записи: 22 перекрёстных ссылок («см. …») и 9 склеек/дублей, снятых в Ф1–Ф3; включены с `kind` для полноты эталона.
- **Страи (60)** — записи каталога без строки мастера — отдельным списком `strays` (cat_pos, титул, том, метод, Ф4-группа).

- Поля оригинального мастера, которых нет ни в alignment, ни в xlsx: флаги Ф1–Ф4 (`flags`), примечания к правкам, история слияний строк. На биекцию не влияют.
