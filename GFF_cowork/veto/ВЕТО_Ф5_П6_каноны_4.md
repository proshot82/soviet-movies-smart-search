## 1. Природа дефекта и метод

Стаб: «Состоит из N сюжетов. <первый сюжет>. <студия сюжета>» — парсер Ф4 обрезал статью
киножурнала после первого «Авт. сцен.»; в томах у каждого сюжета есть проза. Структура
статьи (все тома одинакова): голова → общие титры («Гл. ред. …») → интро «Состоит из N
сюжетов» → блоки сюжетов: строка «Название. [ремарка] [Студия.] Авт. сцен. …»
(титры, могут переноситься на следующую строку) → [«В ролях: …»] → проза (1–3 строки).
В v3 часть сюжетов — «Название». проза без титров.

Разбор: (1) голова статьи по номеру выпуска (список голов серии в томе с выводом
повреждённых OCR номеров по соседям; запасной ход — по первому заголовку из стаба в зоне
между соседними головами); (2) конец статьи — ближайшая следующая голова серии / любая
голова с годом / «Библиография» / потерянная голова внутри диапазона (строка с «19xx г.»);
(3) интро — verbatim (двоеточие → точка); заметка перед интро (cat5742 «Спецвыпуск для
взрослых.») сохранена; (4) сюжет: заголовок = первая фраза титульной строки (или «…» в
кавычках целиком), проза = строки без маркеров титров; ремарки «(По следам…)», студии
сюжетов, «В ролях», колонтитулы «Сов. худ. фильмы вып. N», мусорные сепараторы — не
включены; переносы склеены (дефис сохраняется у «куда-нибудь», «по-умному», «из-за» и
подобных), OCR-звёздочки сняты. Текст = интро + «Заголовок.» + проза по каждому сюжету.
Валидация каждой позиции: число сюжетов == интро; первый заголовок совпадает со стабом;
в тексте нет маркеров титров; текст длиннее стаба. Все 229 позиций прошли (5 — с явной
пометкой, §3). По томам: v3 11, v4 22, v5 18, v6 11, v7 22, v8 23, v9 23, v10 23, v11 18, v12 23, v14 22, v15 13.
