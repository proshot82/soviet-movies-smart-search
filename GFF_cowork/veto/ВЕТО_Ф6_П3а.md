## §1 Метод

1. **Регрессионная сверка** (`work/f6_ref_compare_v2.py`): старый каталог движка `reference/catalog_old_from_db.json` (слой catalog_all_v4.json, 6857; экспорт владельца из старой gosfilmofond.db) сопоставлен с финальным по норм. титулу (+без скобок) и году (±1), затем по началу аннотации (60 норм. знаков), по схожести титула (≥ 0.85), по окну аннотации; 6 остатков с OCR-мусорным титулом — вручную. Первый прогон (по v1) дал 8 несопоставленных старых записей: 6 OCR-титулов, «Что должен знать рабочий и крестьянин о СССР» (в v1 титул склеен из двух строк указателя) и «Старый наездник» (в v1 отсутствует).
2. **Регрессия аннотаций** (`work/f6_ref_lost2.py` → `work/f6_ref_lost3.py`): предложения старой аннотации, отсутствующие в новой (проба 30 норм. знаков, ratio < 0.75), локализуются в печати тома: вне статьи записи → контаминация старого; внутри статьи → класс печатной строки (проза / титры / библиография / призы / голова / соседняя запись). Первый прогон вскрыл классы потерь: примечания «Сценарий…» и «В РСФСР/УССР…» (ложные головы), логлайны перед прозой, новеллы альманахов.
3. **Печатный скан пропусков** (`work/f6_ref_gap_scan.py`, все 7165 непустых аннотаций; независим от старого каталога): область статьи [h2, E) по *настоящим* головам (метраж в строке / прописной титул + титры в следующих строках; ложные головы «В РСФСР фильм не демонстрировался.» больше не режут статью); покрытие каждой печатной строки аннотацией по пробам (устойчиво к чистке П2д); непокрытые строки классифицируются (PRE/GAP/POST × проза/титры/библиография/призы/голова/индекс) и отбираются (`work/f6_ref_gap_select.py`): не киножурналы (k4 — отдельный проход), не формулы, не титроподобные, не покрытые аннотацией соседней записи (границы статей при неопознанных головах). Каждый кандидат верифицирован по печатному контексту (`work/f6_p3_show.py`).
4. **Резолюция** (`work/f6_p3a_manual.py` — спецификации @строк; `work/f6_p3a_build.py` → `scripts/f6_p3a_resolution.json`): текст — verbatim печать + чистка П2д (`work/f6_p3_clean.py`) + точечные OCR-правки с основанием (столбец M); титулы новелл/сюжетов — только начала печатных строк титров (анти-фабрикация, проверка в build). Apply `scripts/f6_apply_p3a.py` (пред-ассерты: вход = вход резолюции по sha256, before байт-в-байт, классы; И1′–И6 с учётом вставки; `--dry`). П3б: `work/f6_p3b_build.py` → `scripts/f6_p3b_resolution.json` → `scripts/f6_apply_p3b.py`.
5. **Приёмка**: `scripts/f6_final_check.py` (независимо от apply: схема, по томам, биекции, реестр, санкции П3а+П3б воспроизводимы, прочие поля байт-в-байт, маркеры/мусор/латиница/переносы, титул ↔ мастер, годы); повторные проходы после применения: tail-scan (`work/f6_p3a_tail_scan.py`), gap-scan (`work/f6_ref_gap_scan_v2.py` + select) и регрессия (`work/f6_ref_lost3.py`) — печатной прозы вне аннотаций не осталось; отчёт `veto/ПРИЁМКА_Ф6.md` §9.
