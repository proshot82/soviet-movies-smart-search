## 1. Метод

Каждый страй сопоставлен с печатной статьёй тома (`work/vN_lines.json`, @строки) и с
соседними связанными записями. Классы и критерии:

| класс | признак | вердикт |
|---|---|---|
| A — служебный мусор тома | предисловие/заголовки разделов | удалить |
| B — дубль-обрывок соседней записи | титул = хвост головы/примечание/обрывок жанра-студии; проза целиком содержится в связанной записи (покрытие прозы цели 1.00 проверено `difflib`, остаток страя — лиды титров, библиография, призы) | удалить; если у страя есть печатное **примечание после прозы**, которого нет у связанной записи, — APPEND к её аннотации |
| B′ — повторная печатная статья того же фильма | v4 3422а «Внимание! В городе волшебник!» при v3 №3386–3387 | удалить; текст — решение владельца (D1) |
| C — части многосерийного фильма / состав сборной программы | проза принадлежит статье связанной записи, у которой она усечена | удалить; RESTORE аннотации цели по печати |
| D — новеллы/сюжеты киноальманахов | в печати новеллы — подзаголовки внутри одной статьи, строки указателя у них нет | удалить; слияние в связанную запись альманаха по правилу k4 (интро + «Название.» + проза) |
| E — законная запись без строки мастера | печатная голова с собственным (литерным) номером | оставить; синтетическая строка мастера; поля почистить по правилам П2/П4 |

Тексты RESTORE/APPEND — verbatim по печати: переносы строк склеены механически (дефис на
конце строки — без пробела), маркеры-«буллеты» OCR сняты, титры/студии новелл/призы/дипломы/
библиография не включены, OCR не «улучшается» (в т.ч. внутристрочные переносы вида «Рябико- ву»).
