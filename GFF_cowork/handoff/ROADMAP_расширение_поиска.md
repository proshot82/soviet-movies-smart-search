# ROADMAP — расширение функционала поиска и каталога (после Ф6)

Замысел владельца: помимо поиска по памяти о сюжете — режим «читать каталог» и
структурные выборки, в т.ч. сложные («все музыкальные комедии 1961–1964»).
Все пункты — правки движка `film_search.py` + UI; переэмбеддинг НЕ требуется
(инвариант движка). Делать после Ф6 на `catalog_final_v1.json`.

## Волна 1 — структурные выборки и чтение (дёшево)

1. **Точный диапазон лет** во всех фильтрах (сейчас только десятилетие: `(year//10)*10`
   в `fts_search`/`semantic_search` → заменить на `year_min`/`year_max`). UI: два поля
   или слайдер. Мультивыбор жанров и студий (IN вместо одиночного LIKE).
2. **Режим «Каталог»**: эндпоинт `/browse` с пагинацией и сортировками (год, алфавит,
   студия, печатный номер); карточка `/film/{id}` с пермалинком, полной аннотацией,
   альт-названиями; **листание тома по печатному порядку** (порядок и номер — из
   alignment/мастера: `index_master_v18r.json` → num, vol; добавить в БД при импорте
   колонки `print_num`, `xlsx_row`).
3. **Поиск по названию** («знаю название»): отдельный режим — леммы по title + rapidfuzz
   для опечаток/OCR-памяти; выдача без реранкера.
4. **Экспорт текущей выборки** в xlsx/CSV (эндпоинт `/export?<фильтры>`).
5. **Страница статистики**: фильмы по годам (гистограмма), топ студий, жанровый состав,
   динамика жанров по десятилетиям (данные — расширение `cmd_stats`).
6. **Случайная карточка** с учётом активных фильтров.

## Волна 2 — на существующих эмбеддингах (доплаты нет)

7. **«Похожие фильмы»** на карточке: топ-10 по косинусу вектора полного чанка фильма
   (вектор фильма = чанк №1 «полный текст»; индекс уже в памяти `_load_index`).
8. **Семантический запрос внутри выборки**: фасеты (годы/жанры/студии) + свободный
   запрос «про что» одновременно — снять декадное ограничение, пробросить мультифильтры
   в `hybrid_search`.

## Волна 3 — курируемая надстройка

9. **Семейства жанров** поверх канона Ф5: словарь-группировщик `genre_families.py`
   (музыкальное, комедийное, экранизации, сказки/детское, киножурналы, историко-
   революционное, документально-художественное …); фильтр UI работает по семействам,
   тонкий канон остаётся в карточке. Делать после закрытия добора genre — по финальному
   инвентарю канонических форм.
10. **Подборки-«полки»**: сохранённые выборки с постоянными ссылками (параметры в URL;
    опционально таблица `shelves` в SQLite).

## За пределами текущих данных (только с новой волной извлечения — решение отдельно)

- Режиссёры/сценаристы/актёры: сняты из каталога сознательно (Ф4 волна 2 — балласт для
  сюжетного поиска). Возврат возможен ТОЛЬКО отдельной волной извлечения титров из томов
  в sidecar-файл (планировался в Ф0 как `catalog_castcredits_v1.json`; существование —
  уточнить). Большой труд; ценность — для режима чтения, не для поиска.
- ВЭ/РУ-даты, метраж, формат — не извлекались; фильтры по ним невозможны без новой волны.

## Технические заметки

- Схема `films` уже содержит нужные колонки; добавить индексы по `year`, `genre`,
  `studio`; новые колонки `print_num`, `xlsx_row` — при импорте финального каталога.
- Все пункты — без переэмбеддинга; правки лемматизации — `reindex-fts`.
- Порядок внедрения: после Ф6/Ф7 и переэмбеддинга, отдельными Cowork-задачами
  «волна 1 → 2 → 3», каждая с вето-протоколом правок движка (Ф7-дисциплина:
  патчи по вето).
