## §1. Правила П6 (анти-фабрикация абсолютна)

1. Меняются поля **genre, studio, annotation, year** — только у санкционированных
   не-страёв, пополево, `before` сверяется байт-в-байт; в одном поколении у одной записи
   меняется одно поле. Значения — только из печатных томов (`work/vN_lines.json`,
   @строки в вето) либо внутрикаталожный канон с явной пометкой класса.
2. **Канон genre серий**: значение = печатная полная форма голов серии («Детский
   юмористический киножурнал» — по головам всех выпусков). Для Фитиля v10 при печатном
   сокращении «Киножурнал» — канон серии «Всесоюзный сатирический киножурнал»
   (обоснование: голова той же статьи печатает «редакция Всесоюзного сатирического
   киножурнала «Фитиль»»); печатная краткая форма фиксируется в вето verbatim.
3. **Канон studio** (решения владельца):
   (а) *кавычки* — одиночное бренд-имя студии без кавычек: `«X»` → `X`, `«X» им. Y` →
   `X им. Y`, `«X» (филиал/примечание)` → `X (…)`; X — имена на -фильм/-филм и
   Союзмультфильм/-научфильм. **Не трогать**: копродукционные и составные строки (два и
   более производителя, «и», запятая-перечисление, «при участии», «совм.»), родовые
   конструкции (киностудия «X», редакция … «Фитиль», т-во «…», акц. о-во «…»), частные
   фирмы v1 («Русь», «Буревестник»);
   (б) *лексика/пунктуация* — варианты одного имени → доминирующая внутрикаталожная форма
   (прецедент cat2356): Белорусьфильм, Беларусь-фильм → Беларусьфильм; Молдова-фильм →
   Молдова-филм; им. А. Бек-Назарова → им. А. Бекназаряна; им. Алты Карлиева →
   им. А. Карлиева; имени → им.; ВГИКа → ВГИК; им. Горького → им. М. Горького;
   им. Довженко → им. А. П. Довженко; Центральная студия детских… → Центральная
   киностудия детских…; Московская/Ленинградская студия научно-популярных фильмов →
   …киностудия…; «киностудия X» (X — бренд) → X; «, Ялтинский филиал» / «, (Ялтинский
   филиал)» → « (Ялтинский филиал)»; «Госкино, Л.», «Севзапкино, М.» → со скобками;
   (в) **не унифицируются**: исторические имена разных эпох (Совкино/Союзкино/Ленфильм;
   Азербайджанфильм и Арменфильм без «им.»; Ташкентская киностудия/Узбекфильм), полные
   официальные формы («Одесская киностудия художественных фильмов», «…художественных и
   хроникальных фильмов»), ветки и отделения (Севзапкино (Л.)/(М.), Пролеткино (Саратов)/
   (Саратовское отд.)), «Советская Беларусь»/«Советская Белорусь» (доминанта сомнительна),
   иностранные студии внутри копродукций. Всё это — в наблюдения для Ф6.
4. **Аннотации**: RESTORE — verbatim по печати (переносы склеивать механически, OCR не
   «улучшать», титры/оркестры/библиографию/призовые блоки не включать); LEAD — точный
   суффикс before; PREFIX — восстановление утраченного начала по печати (after
   заканчивается ровно текущим before). Прозы печатно нет → не трогать (реестр).
5. **Фитиль-сюжеты (k4)**: текст восстановления = печатная интро-строка («Состоит из N
   сюжетов.») + для каждого сюжета «Название сюжета.» + проза сюжета (титры сюжета,
   студия сюжета, ремарки «(По следам…)» — не включаются; сюжет без прозы — только
   название). Существующая стаб-аннотация заменяется целиком; блок с нечитаемым
   заголовком или прозой (OCR-разрушение) — позицию не трогать, в вето с @строками.
   Валидация: число сюжетов в тексте == числу в интро; в after нет маркеров титров.
6. **Год** — только по печатной голове (правила П3: год производства, не ВЭ/РУ).
7. Страи (60) — **не трогать**, стоп-ассерт. Стабы 3876/3877, терминалы очереди —
   не обрабатывать; их состояние фиксируется в реестре стабов.
8. Попутные дефекты прочих полей — только в «наблюдения» вето (титульные — Ф6).

## §3. Apply и инварианты (обязательны, до записи)

`scripts/kN_resolution.json`:
`{"set": {cat: {"field": "genre|studio|annotation|year", "before": …, "after": …,
"vol": "vN"|null, "line": int|[int,…]|null,
"class": "canon|quotes|lex|punct|restore|lead|prefix|year", "note": str}},
"confirm": {cat: {"note"}}}`

Пред-ассерты: длина 7232; страёв 60; **стоп-ассерт: страи запрещены**; поле из
допустимых; `before` == текущее значение байт-в-байт, `after != before`, after непуст и
без крайних пробелов; по классам: `quotes` — after == before со снятыми «» (механически);
`lead` — before.endswith(after); `prefix` — after.endswith(before); `restore` — after без
маркеров титров/библиографии («Авт. сцен», «реж.», «опер.», «звукоопер», «В ролях»,
«Библиография»); `year` — int в диапазоне тома ±1; `canon`/`lex`/`punct` — after из
фиксированного словаря поколения.
Инварианты: И1 длина == 7232; И2 изменившиеся (cat, поле) == санкция, значения ==
резолюция; И3 все прочие поля всех записей байт-в-байт; И4 пер-томовые счётчики;
И5 последовательность (title, source) неизменна. Очередь в П6 не меняется (копируется
в бэкап и остаётся на месте).
