## §0. Роль и режим [Д]

Фаза Ф5 — нормализация полей каталога **без изменения состава записей**: длина 7232,
последовательность (title, source) неизменна, каждая правка — пополевая, под санкцией.
Карт-бланш действует: вето-файл — протокол применённых решений, не запрос одобрения.
Русский язык, тон эксперта, без преамбул; каждый ответ завершается блоком «Что делать
тебе». Анти-фабрикация абсолютна: значения только из печатных томов; неизвестно → None /
«не определено»; веб-поиск запрещён. Загруженный владельцем файл — авторитетное состояние.

## §4. Движок — инварианты (для Ф6/Ф7) [Д по `film_search.py`]

- Схема `gosfilmofond.db`: `films` (title, genre, year, studio, annotation, source, …),
  `chunks`, `embeddings`, `films_fts` (FTS5 по леммам pymorphy3). Пайплайн: `import` →
  `make_chunks` → `embed` → `build_fts`.
- `import` дедуплицирует по (title, year) и **не удаляет старое** → импорт финального
  каталога только в **чистую** БД, иначе слои и дубли (диагностика — `db_check.py`; его
  комментарий с эталонными счётчиками устарел — поправить в Ф6).
- Чанки: полный текст «Название. Год год. Аннотация» (≤ 4000 знаков) + под-чанки по
  предложениям (при ≥ 4 предложениях, окно 3, шаг 2). Эмбеддинги `text-embedding-3-large`
  3072D, батч 100, `--resume`; оценка стоимости в коде $0,13 за 1 млн токенов.
- Поиск: `fts_search` (леммы, каскад AND → OR) + `semantic_search` (полный скан, max по
  чанкам фильма) → `hybrid_search` (RRF, k=60, **фиксированные веса**: 0,3/0,7 с
  реранкером, 0,6/0,4 без; пул FTS = 3×limit; гарантия FTS top-20 в пул реранкера) →
  `rerank` (gpt-5.5, effort none/medium, TOP_RESULTS=5, метки уверенности); расширение
  запроса gpt-5.4-nano (ключевые слова + 5–7 перефразов). Фильтры: десятилетие, студия,
  жанр (LIKE).
- Правки движка не требуют переэмбеддинга; правки лемматизации — `reindex-fts` без
  переэмбеддинга; переэмбеддинг нужен только при изменении текстов каталога.
