# PROMPT Ф5 — добор genre в режиме Cowork (сессия 6+)

Ты продолжаешь фазу Ф5 проекта «Госфильмофонд: каталог + поисковый движок» **в режиме
Cowork**: рабочая папка подключена, файлы читаешь и пишешь на месте. Работай автономно
под действующим карт-бланшем; вето-файл — протокол, не запрос одобрения. Русский язык,
тон эксперта, без преамбул. Финальный отчёт задачи завершай блоком «Что делать тебе».

**Правила добора (источники (а)/(б)/(в), ловушки томов, нормализованный поиск, apply с
инвариантами И1–И5) — в `handoff/PROMPT_Ф5_добор_genre_6.md`, §2–§5. Они не зависят от
режима и действуют полностью. Здесь — только отличия режима Cowork.**

## §0. Раскладка папки (создать недостающие подпапки)

```
state/      catalog_f5_g10.json, Ф5_очередь_docx.json, alignment_v17.json   ← авторитетное состояние
            index_master_v18r.json (+ отчёт реконструкции)                  ← мастер-индекс, в добор genre не нужен
volumes/    «6 1968-1969.docx» … «15 1986-1987.docx»                           ← тома-источники

            f5_apply_g5.py, g5_locate.py-образец, _g*_sanction.json — протоколы)

handoff/    этот файл + PROMPT_Ф5_добор_genre_6.md                              ← правила и состояние
backups/    копии state/* с меткой времени ДО каждой записи                     ← создаёшь сам
```

не нужны; если найдёшь — не читать, доложить в отчёте.

## §2. Цикл по томам

Каждый том — отдельное **поколение** gN (N = 6, 7, 8, …), строго последовательно:

1. `work/vN_lines.json` ← `scripts/f5_extract_lines.py` (сырой XML, таблицы, AlternateContent).
2. Локализация всех активных позиций тома нормализованным поиском (игла и стог через
   одну norm-функцию; гомоглифы 0↔О, **°↔О**, 4↔Ч, I↔1, лат↔кир, ё↔е, П↔Н, Й↔И).
3. Вердикты по (а)/(б)/(в); канонизация словарём `scripts/f5_genre_map.py`
   (+FITIL-правило до словаря); новые формы → в словарь (секция с пометкой поколения).
4. **Бэкап**: `backups/catalog_f5_g{N-1}_<ГГГГММДД-ЧЧММ>.json` и такой же для очереди —
   до записи.
5. Apply с пред-ассертами и И1–И5 (образец `f5_apply_g5.py`: три класса — санкция /
   терминал / недобор; стоп-ассерт на страи). Запись: `state/catalog_f5_gN.json`,
   `state/Ф5_очередь_docx.json` (на место). Предыдущий `state/catalog_f5_g{N-1}.json`
   переместить в `backups/`, чтобы в `state/` лежал ровно один каталог.
6. `veto/ВЕТО_Ф5_добор_genre_N.md` — по форме вето-5: таблицы добрано / терминалы /
   недоборы / новые словарные формы / наблюдения вне охвата / контрольные цифры.
7. `scripts/_gN_sanction.json`, `scripts/gN_resolution.json` — протоколы.
8. Обнови §1 п.2–3 **этого файла** (контрольные цифры, остаток по томам, список
   закрытых) — следующая задача стартует с него.

Если контекст задачи подходит к пределу — завершай на границе поколения (после п.8),
не посередине тома; незакрытый том останется в очереди нетронутым.

## §3. Финальный отчёт задачи

Кратко: какие поколения закрыты, сколько правок / терминалов / недоборов, новые
словарные формы, наблюдения в будущие волны (год-кандидаты, лиды аннотаций,
альт-названия — см. вето-5 §5 как образец), состояние `state/`, что осталось.
Блок «Что делать тебе» — простые шаги без проектного жаргона.

## §4. Что не меняется

Анти-фабрикация абсолютна: значения только из печатных томов, веб-поиск запрещён;
«не найдено» → None с пометкой причины в очереди; страи `alignment_v17.json`
(`xlsx_row=None`, 60 поз.) не трогать; терминальные позиции (`note`) не обрабатывать,
только переносить; загруженные владельцем правки в `state/` — авторитетны, не
оспаривать; JSON только через Python, `json.dump(..., ensure_ascii=False, indent=1)`.
