## §1. Правила Ф6

1. **Состав записей** меняется только по `Ф6_страи_диспозиция.json` (П1) — никаких иных
   удалений/слияний. Порядок оставшихся записей = порядок Ф5.
2. **Тексты** RESTORE/APPEND берутся из диспозиции как есть (verbatim по печати, уже
   проверены); при расхождении `before` с каталогом — стоп.
3. **Титулы** правятся только по указателю тома/мастера (`index_master_f6_p1.json → xlsx_title`,
   `title_canon`) либо по печатной голове с @строкой; каждая правка титула синхронно меняет
   `master_title` в alignment и `title_canon` в мастере (единый референс «фильм-год»).
4. **Поля** — правила Ф5 без изменений: год производства (П3), аннотация-проза без титров/
   библиографии/призов (П4), студия без метража/кавычек бренд-имени/года (П5), каноны серий и
   лексика студий (П6). Значения — только печатные.
5. **Схема финала**: `id` (1..N сквозной по порядку записей), `title, genre, year, studio,
   annotation, source`; служебные ключи снимаются; `annotation` None только у позиций реестра.
6. Страи после П1 не существуют; реестр стабов — единственный список законных пустот.
7. Движок (`film_search.py`, `gosfilmofond.db`) в Ф6 **не правится** (Ф7); импорт — только в
   чистую БД (см. П4 и §6 п.4 о ключе дедупликации).
