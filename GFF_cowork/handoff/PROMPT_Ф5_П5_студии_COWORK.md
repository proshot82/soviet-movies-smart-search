## §1. Правила студийной правки (анти-фабрикация абсолютна)

1. Меняется **только поле studio** и только у санкционированных не-страёв. Источник
   значения — печатная голова статьи тома (`work/vN_lines.json`, @строка в вето);
   для OCR-класса при дефектной печати — доминирующая внутрикаталожная форма той же
   студии (прецедент cat2356), с явной пометкой в вето.
2. Форма поля: студия(и) **без** метража/числа частей/формата/года/ВЭ-РУ (норма П2).
   Кавычки — «ёлочки»; OCR-формы („ “ ” " < >>) приводить как в prefix_fixes П2.
   Печатную орфографию студии сохранять как в голове; дефисные переносы склеивать
   механически; окончания и падежи не «улучшать».
3. Копродукции: печатная форма соединения сохраняется («X и Y», «X, Y»,
   «X (СССР) и Y (страна)», «при участии …»). Флаг «лид-и»: локализовать голову,
   прочитать строки выше маркера — печатно перед «и» стоит первый копродуцент →
   восстановить полную форму; «и» — OCR-клякса (остаток рисунка/штампа скана) →
   confirm без правки; остаточный мусор в текущем значении — срезать (класс junk).
4. **НЕ унифицировать** канонические написания между записями: «Мосфильм»/Мосфильм
   без кавычек, им./имени, полная/короткая форма студии — законная печатная
   вариативность томов разных лет; разнобой канонов — П6/Ф6, в П5 только наблюдение.
   Правится только дефект (OCR, обрезка, чужая студия, мусор), не вариативность.
5. Пустой слот: голова найдена → печатная студия; студии в голове печатно нет или
   головы нет → None с note (терминал очереди); новелла сборника без собственной
   головы → терминал с note.
6. Страи (60) — **не трогать**, стоп-ассерт; мусор в studio страёв (0, 121,
   3147–3149) фиксировать в вето для Ф6, не править.
7. Сдвиговый класс: перед заменой подтвердить по тому пару признаков — сюжетная
   аннотация записи соответствует статье тома И печатная студия головы ≠ каталожной.
   Одностороннее совпадение — в сомнительные, не править.
8. Попутные дефекты прочих полей — только в «наблюдения» вето (титульные — Ф6).

"line": int|[int,…]|null, "class": "shift|fill|copro|ocr|junk|tail|none", "note": str}},
"confirm": {cat: {"note"}}, "notfound": {cat: {"note"}}}`

Пред-ассерты: длина 7232; страёв 60; классы/секции не пересекаются; **стоп-ассерт:
страи запрещены во всех классах**; для set — `before` == текущее значение байт-в-байт,
`after != before`; `after=null` только class=none с note; для fill `before` null.

резолюция; И3 все поля, кроме studio, байт-в-байт; И4 пер-томовые счётчики; И5
последовательность (title, source) неизменна.
