## §2. Задача сессии

Для каждой позиции очереди `genre`, чей `vol` совпадает с загруженными томами: найти
статью в томе и добрать жанр. Приоритет источников (анти-фабрикация абсолютна):
1. **(а) печатная голова статьи** — формат: «НАЗВАНИЕ. Жанр, метраж/формат, студия,
   год, ВЭ/РУ»; жанр — первое слово(сочетание) после названия;
2. **(б) контекст аннотации** — только явные жанровые самоназвания («фильм-спектакль
   по…», «киноальманах состоит из…», «сборник включал…»/«составлен из … фильмов» —
   прецеденты g3, g4); умозаключения запрещены; «По мотивам/пьесе/роману…» — ссылка
   на литисточник, НЕ самоназвание (прецедент g5 cat3878);
3. **(в) не найдено → оставить None**, позицию оставить в очереди с пометкой причины
   («головы нет физически» / «разрыв источника» — при подтверждённой утрате и в
   оригинальном скане вердикт терминален: класс «источник утрачен», прецедент g5
   cat3876/3877/3878; «страница нечитаема»; «записи в томе нет»; «жанр в голове печатно отсутствует» — терминалы:
   конвенция подтверждена для всего старого блока v1–v4 И прецедентом нового тома
   v5 cat3915 — пустой жанровый слот при цельной пунктуации головы возможен и в
   новых томах; перед вердиктом проверять аннотацию на самоназвание).

Найденные сырые формы канонизировать словарём `f5_genre_map.MAP` (+FITIL-правило до
словаря для «Фитиль №…»; g5-прецедент: FITIL применим и к физически утраченной голове
при трёхфакторной идентификации — номерная последовательность + дословные сюжеты +
студия/год). Регистр нормализовать до словаря (прецеденты «экраниз.» строчными: v3
cat2622, v4 cat3601/3602). Новые формы вне словаря — привести к стандартам П1 (полная
форма, развороты сокращений, квалификаторы срезать, анимационная триада → «Анимация»)
и вынести отдельной таблицей в вето-файл. Полные канонические формы («Драма»,
«Киноповесть», «Кинороман», «Фильм-сказка», «Научно-популярный» и т.п.) проходят
identity, в словарь не вносятся.

## §3. Чтение томов — ловушки (пополнено g1–g5)

- **python-docx запрещён проектно.** Читать сырым XML: `zipfile` → `word/document.xml`
  → `ElementTree`. Обход `mc:AlternateContent`: брать ветку `mc:Choice`, при пустой —
  `mc:Fallback` (не обе — дубли); вложенные `w:p` текстбоксов — отдельными строками.
  **Контент может лежать в таблицах `w:tbl`** (v3: 18,9 тыс. строк из 28,9 тыс.; в v4
  таблицы тоже массивны — 10,5 тыс. строк) — извлекать `w:p` и из таблиц (образец —
  `f5_extract_lines.py`). Проверять каждый том.
- Порядковый номер фильма в новых томах — картинка → OCR-мусор перед названием
  («(ф», «<б)», «Л», «₽^)», «®@^^») — не часть головы. В v1, v2, v4 печатные номера
  частично распознаны и прилипают к титулу («Я8. ГОЛОД», «3541. ЮЖНЫЙ УЗЕЛ»).
- **Гомоглифы в титулах голов**: помимо 0↔О, 4↔Ч, I↔1, лат↔кир, ё↔е, П↔Н —
  **«°»→«О»** (g5: «В Н°ЧЬ», «ЛЕТО 1943 Г°АА»); знак градуса удаляется наивным
  нормализатором как пунктуация и рвёт подстроку — включить замену °→О в norm.
- **Иглу прогонять той же norm-функцией, что и стог** (методправило g4).
- **Физический разрыв docx** (новый класс, g5): цели есть в алфавитном указателе, но
  0 совпадений в теле; алфавитные соседи смыкаются через пустую строку; каталожные
  аннотации целей пусты/усечены. Вердикт «головы нет физически»; уточнить у
  владельца, есть ли страницы в оригинальном скане: есть — добор при переконвертации,
  нет — терминально None по утрате источника (прецедент g5); в очередь — `note` +
  координаты разрыва.
- **Старые тома (v1–v4): жанр в голове может печатно отсутствовать** (издательская
  конвенция; закрытый счёт: v1 — 4, v2 — 3, v3 — 1, v4 — 1). **Прецедент v5
  (cat3915)**: пустой слот возможен и в новых томах у нестандартных единиц —
  признак: запятая сразу после названия при цельной строке. Вердикт после проверки
  аннотации на самоназвание.
- Жанр в голове может быть **строчными** — регистр нормализовать до словаря.
- **Прилипание головы** к хвосту библиографии предыдущей записи (v1: cat861 @5822) —
  при отсутствии титула отдельной строкой искать его внутри длинных строк.
- **Киножурналы («Фитиль №…», «Ералаш №…»)**: жанр головы часто переносится на 2-ю
  строку; номер выпуска нередко съеден OCR — идентифицировать по месту в номерной
  последовательности, датам ВЭ/РУ соседей и совпадению сюжетов с аннотацией каталога.
- **Запятая-OCR в сокращениях**: «Истории, драма» = «Историч. драма». Родственный
  дефект: точка сокращения съедена — «Ист -рев.» (в словаре).
- **Канон Ералашей** — «Детский юмористический киножурнал» (разнобой 56 старых записей —
  отдельная волна, зафиксирован в `ВЕТО_Ф5_добор_genre_1.md`).
- **Подменыши**: 1–2 на том — при подозрении сверять год+студию+аннотацию.

## §4. Поиск записи в томе

Нормализованный поиск, не точная строка: гомоглифы (0↔О, °↔О, 4↔Ч, I↔1, лат↔кир,
ё↔е, П↔Н, Й↔И), пунктуационная коррозия, переносы, разрывы внутри слова («РЕЙТ АН»,
«ЛИЧНАЯ ЖИЗНЬКУЗЯЕВА»). Иглу и стог — через одну norm-функцию. Вердикт «записи в томе
нет» — только после провала по ≥3 независимым маркерам (нормализованное название, год,
студия, редкий фрагмент аннотации ≥25 знаков, альт-названия, сюжетные
имена/маркеры). Прецеденты: g1 — пять разрушенных титулов v14; g2 — пять локализаций
v1; g3 — 26/26 v2 с первого прохода; g4 — 9/9 v3 после нормализации иглы; g5 — 24/27
локализовано (2 добраны через контекст при изуродованных гомоглифами титулах,
3 подтверждённо отсутствуют физически).

## §5. Apply и инварианты (обязательны, до записи файла)

Правки применять одним скриптом с пред-ассертами (образец — `f5_apply_g5.py`,
включая стоп-ассерт «страи в санкции запрещены» и трёхклассную обработку:
санкция / терминал / недобор-разрыв, последние два — перенос в очереди с `note`).
Инварианты: И1 длина == 7232; И2 изменения == санкция пополево (только `genre`,
только позиции из очереди, только не-страи); И3 снимок-тест: все прочие поля
байт-в-байт; И4 пер-томовые счётчики записей; И5 последовательность (title, source)
неизменна.

## §6. Выход сессии → `/mnt/user-data/outputs/`

1. `catalog_f5_g6.json` — каталог после добора (следующая сессия — g7 и т.д.);
2. `ВЕТО_Ф5_добор_genre_6.md` — полные таблицы: добрано (cat, том, название, строка,
   сырая форма verbatim → канон, источник а/б), не найдено с причинами, новые словарные
   формы;
3. `Ф5_очередь_docx.json` обновлённая (закрытые позиции удалены, ненайденные с пометкой;
   помеченные `note` переносить без изменений);
4. обновлённый `f5_genre_map.py` при новых формах + свежий tar скриптов;
5. handoff-промпт следующей сессии.
