## §1. Правила года (методика Ф5, анти-фабрикация абсолютна)

1. Целевое значение — год **производства** из **печатной головы статьи** тома. Формат
   головы: «НАЗВАНИЕ. Жанр, метраж/формат, студия, ГГГГ г., ВЭ/РУ дата». Год ВЭ/РУ
   **не является** годом производства и в поле year не пишется.
2. Источники по приоритету:
   - **(а)** голова статьи в docx-томе (единственный первичный источник значений);
   - **(б)** именной указатель — `state/index_master_v18r.json` (`xlsx_year`):
     пофильмовый год существует **только v5+**; в v1–v4 там диапазон тома — не источник.
     Эмпирика входа: все 14 кандидатов v5+ совпали с указателем. Концорданс (а)==(б) —
     сильная санкция; расхождение (а)≠(б) — разбирать отдельно, в вето;
   - **(в)** голова не найдена/год нечитаем и не доказуем → year не менять (для empty
     остаётся None), позиция остаётся в очереди с `note` причины.
3. **Кандидаты**: флаг из П2-очистки студийного поля — не санкция. Санкция — только
   чётко читаемый печатный год головы. Голова может подтвердить **текущий** каталожный
   год (флаг = OCR-мусор) → класс «подтверждён, без правки»: каталог не трогать,
   позицию закрыть, зафиксировать в вето.
4. **Печатный диапазон** «ГГГГ—ГГГГ гг.» → year := **поздний** год (завершение
   производства). Конвенция подтверждена указателем тома: v7 cat4349, cat4435 — оба
   «1969—1970» → 1970 в указателе. Полный диапазон — в вето.
5. **OCR-коррозия цифр** в головах: «I960»→1960, «¡954»→1954, «192 7»→1927, «*926»,
   «193$», «1 48» и т.п. Восстанавливать цифру только по печатной голове docx; если
   коррозия и там — вторичные печатные признаки той же статьи/тома: дата ВЭ (год
   производства ≤ года ВЭ), головы соседей, студийный указатель тома (секции по годам),
   именной указатель (v5+). Недоказуемо → правило 2(в).
6. **Окно правдоподобия**: [нижняя метка тома − 1; верхняя метка тома]. Нижняя метка
   v2 — **1930** (физический том «2 1930-1957»), остальные — по меткам источников.
   Выход санкции за окно — стоп-репорт, молча не применять.
7. Установленные координаты (проверить по извлечению, затем санкционировать):
   cat500 — голова v1, год **1927** (g2, строка 3423 извлечения v1);
   cat3601/3602 «Война и мир» I/II — кандидат **1965** подтверждён головами v4
   (@3760/@3766 извлечения g5); cat1186 — §0; cat854 — год из головы v1 (1905 — мусор
   из альт-названия «1905 год», вне окна).
8. Меняется **только поле year** и только у 116 целей. Страи (32 в year_empty) не
   трогать и не резолвить — переносить как есть (диспозиция — Ф6). Попутные дефекты
   студий/аннотаций — в вето «наблюдения», поля не трогать.
