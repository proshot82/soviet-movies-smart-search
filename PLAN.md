# План работы над проектом

**Цель:** полная база советских кинофильмов, телефильмов, телеспектаклей и мультфильмов 1917–1991 годов с максимально полными сюжетными аннотациями и умным поиском по ней. Поиск работает локально (`serve.bat`) и на GitHub Pages (`docs/`).

Состояние на 19.10.2026. Цифры получены запросами к `gosfilmofond.db` в этот день.

**База `gosfilmofond.db`** (Git LFS, 924 МБ): 14 477 фильмов, 64 665 фрагментов, у всех есть эмбеддинги (на 19.10.2026, после этапов 2 и 3.1).

| Тип (`films.kind`) | Фильмов | Откуда |
|---|---|---|
| кинофильм | 7144 | 1918–1987 — печатные каталоги ГФФ; 1988–1991 и пропуски — списки владельца |
| телефильм | 1626 | список телефильмов владельца (аннотации в основном с kino-teatr.ru) |
| фильм-спектакль | 1359 | kino-teatr.ru (в `source` у 1565 фильмов есть URL) |
| мультфильм | 3737 | каталоги ГФФ (654) и animator.ru + список владельца (3083, film_id 11395–14477) |

- **`film_id` 1–7174** — каталоги Госфильмофонда 1918–1987. **Эти записи закрыты: аннотации не трогаем.**
- **`film_id` 7175–11394** — добавлены 19.10.2026 из `Кино_СССР сводный каталог.xlsx` и `Кино_СССР телефильмы и пропуски включить в базу.xlsx`. Отчёт сверки — `imports/2026-10_телефильмы_и_пропуски_отчёт.xlsx`.

**Инструменты:**

| Команда | Что делает |
|---|---|
| `python film_search.py serve` / `serve.bat` | локальный поиск: слова + смысл + переоценка моделью gpt-5.5 |
| `python tools/xlsx_to_json.py …` | сверка xlsx с базой → JSON для импорта и отчёт xlsx |
| `python tools/annotation_worklist.py export / apply` | список работ по аннотациям; заполненный xlsx → JSON-правки |

| `python film_search.py import файл.json [--dry-run]` | новые фильмы; запись с `film_id` — правка существующего |

Порядок пополнения расписан в `tools/README.md`.

## 2. Правила для любой сессии

1. **Аннотации `film_id` 1–7174 не менять.** Метаданные (тип, студию) — только по согласованию с владельцем.
2. **Перед записью в базу:**
   - сделать копию `gosfilmofond.db`;
   - прогнать `import --dry-run`;
   - после импорта: `embed --resume` (**никогда без `--resume`**: без него пересчитываются все 54 тыс. фрагментов) → `stats` → `pages/build_site.py` → `pages/check_parity.py`.
3. **Изменили поиск в `film_search.py` — меняйте и `docs/engine.js`.** Затем `check_parity.py` должен показать полное совпадение.
4. **`film_search.py` хранится с переводами строк CRLF.** Редактировать, не меняя их, иначе дифф затронет весь файл.
5. **База в Git LFS:** каждая загруженная версия занимает ~0,9 ГБ из бесплатных 10 ГиБ (после 19.10.2026 занято ~2,3 ГБ). Коммитить базу пачками, а не после каждого шага.
6. **Расходы OpenAI:**
   - эмбеддинг ~ $0,13 за 1 млн токенов (цена взята из кода, не проверялась); 4220 фильмов с короткими аннотациями обошлись в $0,15;
   - переоценка gpt-5.5 — около 20 тыс. входных токенов на каждый поиск.
7. **Чужие сайты:** соблюдать `robots.txt` и условия использования, проверки «я не робот» не обходить. Указывать источник аннотации в `films.source`.
8. **LLM не сочиняет аннотации:** велик риск выдуманных подробностей. Модель можно использовать для классификации («описывает ли текст сюжет»), чистки и сверки.

### Этап 2. Полные сюжетные аннотации для фильмов 7175–11394 — ПЕРВАЯ ПАЧКА ГОТОВА (19.10.2026)

**Итог первой пачки** (среди film_id 7175–11394):

| | было | стало |
|---|---|---|
| короче 300 символов | 2497 (59%) | 1975 (46,8%) |
| обрыв на «…» / «...» | 604 | 428 |
| заменено аннотаций | — | 1042: 299 с gosfilmofond.ru, 743 из Википедии |

- «Семнадцать мгновений весны» (8327) находится по общему описанию сюжета на 1-м месте; раньше его не было даже среди кандидатов. «Винни-Пух», «Тот самый Мюнхгаузен» — тоже 1-е место.
- Аннотации film_id 1–7174 не менялись: сверено с копией базы до импорта.

**Источники и правила** (решения владельца 19.10.2026):
- **gosfilmofond.ru — основной источник.** Каталог выгружен целиком (`tools/gff_site_catalog.py` → `imports/gff_site_catalog.jsonl.gz`, 59 306 фильмов).
  - Выгрузка идёт через `admin-ajax.php`, который `robots.txt` разрешает явно. Карта сайта и поиск закрыты, их не трогаем.
  - На сайте «©», лицензии нет; владелец принял его как источник.
- **Википедия — второй источник.** Берётся раздел «Сюжет» (`tools/wiki_plots.py` → `imports/wiki_plots.jsonl.gz`), лицензия CC BY-SA 4.0. В `films.source` — постоянная ссылка на версию статьи; на сайте есть строка о лицензии.
- **Правило для сериалов:**
  - при сквозном сюжете нужен только общий сюжет, посерийный не берём;
  - если серии — отдельные истории («Следствие ведут знатоки»), нужен сюжет каждой серии.
  - Тип сериала определяет модель, решения и ручные правки лежат в `imports/аннотации_сериалы.json`.
- **kino-teatr.ru** — отложен владельцем.

**Как отбираются тексты** (`tools/annotation_worklist.py export --gff … --wiki …`):
- **Совпадение:** то же название и год ±1. Телеспектаклю описание кинофильма не предлагается — это другая постановка той же пьесы.
- **Новый текст должен быть лучше:** не обрыв и длиннее старого. Если старый не обрыв и не «не сюжет», новый длиннее хотя бы на 40 символов.
- **Сверка «тот же фильм?»** — `gpt-5.4-mini`, затем ручная проверка всех отказов и сомнительных пар. Решения в `imports/аннотации_сверка.json`. Модель сначала путала мелкие расхождения (имя одного героя) с другим фильмом, промпт исправлен.
- **Применение:** `apply` → JSON → `import`. Правки пачки — `imports/2026-10_аннотации_гфф_википедия.json`.
- **Вторым заходом** (после импорта мультфильмов) — 269 текстов ГФФ для мультфильмов (вместо «Для детей» или пустоты) и 40 исправлений латинских букв в русских словах («капpизов» → «капризов»; такие слова не находились поиском по словам). Правки — `imports/2026-10_аннотации_мультфильмы_гфф_исправления.json`.
- **Расходы за 19.10:** классификация «не сюжет» ≈ $1,5 (вместе с мультфильмами), сверки ≈ $0,4, эмбеддинги ≈ $0,3.

**Что осталось:**
1. **Телеспектакли** — главный пробел. Из 1298 у Википедии сюжет есть только у 71, на сайте ГФФ их почти нет. Нужен источник; kino-teatr.ru отложен.
2. **428 обрывов и 1264 «не сюжета»** без замены — в `imports/аннотации_список_работ.xlsx`. Колонки «Новая аннотация» и «Источник» можно заполнять вручную, затем `apply`.
3. **50 сериалов со сквозным сюжетом**, у которых в Википедии только посерийный сюжет («Гостья из будущего», «12 стульев»), остались со старыми аннотациями. Общий сюжет надо искать в другом источнике.
4. **Размер индекса:** у 1042 текстов медиана 1080 символов, максимум 11,5 тыс. Фрагментов 64 665 вместо 54 005 (вместе с мультфильмами), `docs/data` — 36,6 МБ вместо 31 МБ. Пока терпимо.
