# План работы над проектом

**Цель:** полная база советских кинофильмов, телефильмов, телеспектаклей и мультфильмов 1917–1991 годов с максимально полными сюжетными аннотациями и умным поиском по ней. Поиск работает локально (`serve.bat`) и на GitHub Pages (`docs/`).

Состояние на 19.10.2026. Цифры получены запросами к `gosfilmofond.db` в этот день.

## 2. Правила для любой сессии

1. **Аннотации `film_id` 1–7174 не менять.** Метаданные (тип, студию) — только по согласованию с владельцем.
2. **Перед записью в базу:**
   - сделать копию `gosfilmofond.db`;
   - прогнать `import --dry-run`;
   - после импорта: `embed --resume` (**никогда без `--resume`**: без него пересчитываются все 54 тыс. фрагментов) → `stats` → `pages/build_site.py` → `pages/check_parity.py`.
3. **Изменили поиск в `film_search.py` — меняйте и `docs/engine.js`.** Затем `check_parity.py` должен показать полное совпадение.
4. **`film_search.py` хранится с переводами строк CRLF.** Редактировать, не меняя их, иначе дифф затронет весь файл.
5. **База в Git LFS:** каждая загруженная версия занимает ~0,9 ГБ из бесплатных 10 ГиБ (после 19.10.2026 занято ~2,3 ГБ). Коммитить базу пачками, а не после каждого шага.
6. **Расходы OpenAI:**
   - эмбеддинг ~ $0,13 за 1 млн токенов (цена взята из кода, не проверялась); 4220 фильмов с короткими аннотациями обошлись в $0,15;
   - переоценка gpt-5.5 — около 20 тыс. входных токенов на каждый поиск.
7. **Чужие сайты:** соблюдать `robots.txt` и условия использования, проверки «я не робот» не обходить. Указывать источник аннотации в `films.source`.
8. **Сюжеты — только по найденным источникам.** Решение владельца 20.10.2026: сюжет можно искать где угодно (сайты, форумы, книги, онлайн-кинотеатры) и собирать пересказ из нескольких источников.
   - Пересказывается только то, что нашлось; развязку не додумывать.
   - Проверять, что источник о том же фильме: год, студия, режиссёр, тип. Другая экранизация или литературный первоисточник не годятся.
   - Все источники перечисляются в `films.source`.
   - Не нашлось — оставить как есть: честное «не нашёл» лучше чужого сюжета.
   - Поиск ведёт Claude своими инструментами (веб-поиск, Exa), не через API OpenAI.
   - Телеспектакль: если описания постановки нет, можно пересказать сюжет пьесы с пометкой «Сюжет пьесы:» (решение владельца 20.10.2026). Проза, опера, оперетта, балет — сюжет первоисточника не пересказывается.

**Как отбираются тексты** (`tools/annotation_worklist.py export --gff … --wiki …`):
- **Совпадение:** то же название и год ±1. Телеспектаклю описание кинофильма не предлагается — это другая постановка той же пьесы.
- **Новый текст должен быть лучше:** не обрыв и длиннее старого. Если старый не обрыв и не «не сюжет», новый длиннее хотя бы на 40 символов.
- **Сверка «тот же фильм?»** — `gpt-5.4-mini`, затем ручная проверка всех отказов и сомнительных пар. Решения в `imports/аннотации_сверка.json`. Модель сначала путала мелкие расхождения (имя одного героя) с другим фильмом, промпт исправлен.
- **Применение:** `apply` → JSON → `import`. Правки пачки — `imports/2026-10_аннотации_гфф_википедия.json`.
- **Вторым заходом** (после импорта мультфильмов) — 269 текстов ГФФ для мультфильмов (вместо «Для детей» или пустоты) и 40 исправлений латинских букв в русских словах («капpизов» → «капризов»; такие слова не находились поиском по словам). Правки — `imports/2026-10_аннотации_мультфильмы_гфф_исправления.json`.
- **Расходы за 19.10:** классификация «не сюжет» ≈ $1,5 (вместе с мультфильмами), сверки ≈ $0,4, эмбеддинги ≈ $0,3.
